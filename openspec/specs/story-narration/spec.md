# story-narration Specification

## Purpose
Синтез речи по готовому тексту сказки: страницы озвучиваются выбранным голосом и склеиваются в один аудиофайл прогона, который бот отдаёт пользователю вместе с книжкой.

## Requirements

### Requirement: Озвучка только текста страниц

Система ДОЛЖНА (SHALL) озвучивать исключительно тексты страниц в порядке их номеров. Система ДОЛЖНА (SHALL) не добавлять от себя вступление, заголовок сказки, обращение к слушателю, мораль или слово «Конец», и ДОЛЖНА (SHALL) сохранять между страницами короткую паузу, чтобы границы страниц были слышны.

#### Scenario: Текст страниц идёт по порядку
- **WHEN** сказка содержит страницы 1..N
- **THEN** в аудиофайле звучат тексты этих страниц без пропусков и в порядке номеров

#### Scenario: Ничего не дописано от системы
- **WHEN** аудиофайл озвучен
- **THEN** в нём нет вступления, заголовка, морали и завершающей фразы, которых нет в текстах страниц

#### Scenario: Границы страниц слышны
- **WHEN** озвучиваются две соседние страницы
- **THEN** между их текстами есть короткая пауза, а не слитная речь

### Requirement: Один аудиофайл на всю сказку

Результатом озвучки ДОЛЖЕН (SHALL) быть ровно один аудиофайл, содержащий все страницы сказки, пригодный для отправки в мессенджер. Длительность файла ДОЛЖНА (SHALL) соответствовать суммарной длительности озвученных страниц.

#### Scenario: Файл один
- **WHEN** озвучка завершена
- **THEN** в каталоге прогона есть один аудиофайл озвучки, а не набор файлов по страницам

#### Scenario: Все страницы попали в файл
- **WHEN** сказка содержит N страниц с текстом
- **THEN** аудиофайл содержит озвучку всех N страниц

### Requirement: Выбор голоса прогона

Система ДОЛЖНА (SHALL) поддерживать два голоса озвучки — женский и мужской — и ДОЛЖНА (SHALL) озвучивать прогон тем голосом, который выбрал пользователь. Голос ДОЛЖЕН (SHALL) быть частью входа прогона и ДОЛЖЕН (SHALL) влиять только на синтез речи, не меняя ни текст, ни иллюстрации.

#### Scenario: Женский голос
- **WHEN** прогон запущен с женским голосом
- **THEN** аудиофайл озвучен женским голосом

#### Scenario: Мужской голос
- **WHEN** прогон запущен с мужским голосом
- **THEN** аудиофайл озвучен мужским голосом

#### Scenario: Голос не влияет на книжку
- **WHEN** два прогона отличаются только голосом
- **THEN** тексты страниц и иллюстрации у них не различаются из-за выбора голоса

### Requirement: Заменяемый провайдер синтеза речи

Синтез речи ДОЛЖЕН (SHALL) выполняться через заменяемый провайдер, а не напрямую из этапов пайплайна, чтобы прогон можно было выполнить без реальных платных обращений. Конкретный вендор и модель ДОЛЖНЫ (SHALL) задаваться настройками, а не быть зашитыми в бизнес-логику. При отсутствии ключа провайдера система ДОЛЖНА (SHALL) использовать mock-режим: не выполнять платных обращений и всё равно отдавать пригодный аудиофайл, чтобы прогон и тесты не падали.

#### Scenario: Mock без ключа
- **WHEN** ключ провайдера синтеза речи пуст
- **THEN** прогон использует mock-провайдер, реальных обращений к API не происходит, а прогон завершается с аудиофайлом

#### Scenario: Смена модели настройкой
- **WHEN** в настройках задана другая модель или голос
- **THEN** прогон использует именно их, без правки кода этапов

### Requirement: Озвучка не удлиняет прогон

Озвучка ДОЛЖНА (SHALL) выполняться параллельно с генерацией иллюстраций: текст страниц к этому моменту уже готов, а синтез речи не зависит от картинок. Сбой или задержка синтеза речи ДОЛЖНЫ (SHALL) не мешать выпуску иллюстраций.

#### Scenario: Синтез идёт вместе с рисованием
- **WHEN** пайплайн перешёл к этапу иллюстраций
- **THEN** синтез речи выполняется одновременно с рисованием, а не строго после него

#### Scenario: Задержка синтеза не блокирует картинки
- **WHEN** синтез речи отвечает медленнее, чем генерация иллюстраций
- **THEN** иллюстрации не ждут окончания синтеза

### Requirement: Устойчивость к сбоям синтеза

Синтез речи ДОЛЖЕН (SHALL) переживать временные сбои провайдера: таймаут, ответ со статусом ошибки и пустой аудиопоток ДОЛЖНЫ (SHALL) обрабатываться повтором в разумном пределе, а затем — управляемой ошибкой этапа. Управляемая ошибка озвучки ДОЛЖНА (SHALL) не отменять уже готовую книжку и не менять её статус, а ДОЛЖНА (SHALL) фиксироваться в состоянии и метриках прогона как отсутствие озвучки.

#### Scenario: Временный сбой с последующим успехом
- **WHEN** первый вызов синтеза завершился таймаутом, а повтор завершился успешно
- **THEN** прогон продолжается и получает аудиофайл

#### Scenario: Провайдер вернул ошибку
- **WHEN** провайдер отвечает статусом ошибки после исчерпания повторов
- **THEN** прогон помечает озвучку как несостоявшуюся, сохраняет книжку и её статус и продолжает выдачу

#### Scenario: Пустой аудиопоток
- **WHEN** провайдер вернул успешный статус, но пустое аудио
- **THEN** такой ответ считается неудачей озвучки, а не валидным результатом

### Requirement: Артефакт и наблюдаемость озвучки

Система ДОЛЖНА (SHALL) сохранять аудиофайл в каталоге прогона рядом с файлами страниц и ДОЛЖНА (SHALL) фиксировать в состоянии прогона путь к аудиофайлу и метрики этапа синтеза (длительность, число сегментов, признак сбоя). Состояние ДОЛЖНО (SHALL) оставаться сериализуемым без бинарных данных: аудио представлено путём, а не содержимым.

#### Scenario: Файл лежит в каталоге прогона
- **WHEN** озвучка завершилась успешно
- **THEN** аудиофайл находится в каталоге этого прогона рядом с файлами страниц

#### Scenario: Путь виден в артефакте прогона
- **WHEN** прогон завершён
- **THEN** сохранённое состояние содержит путь к аудиофайлу и метрики этапа синтеза

#### Scenario: Бинарные данные не попадают в состояние
- **WHEN** состояние сериализуется
- **THEN** в нём нет байтов аудио, только путь к файлу и метаданные

### Requirement: Настройки озвучки

Параметры озвучки — модель синтеза, голоса для женского и мужского варианта, манера чтения, таймаут и число повторов — ДОЛЖНЫ (SHALL) задаваться настройками окружения без правки кода. Некорректные значения (пустая модель, неизвестный голос, неположительный таймаут) ДОЛЖНЫ (SHALL) обнаруживаться при загрузке настроек, до первого платного вызова.

#### Scenario: Параметры задаются окружением
- **WHEN** в окружении заданы модель, голоса и манера чтения
- **THEN** синтез использует эти значения

#### Scenario: Некорректное значение отклоняется заранее
- **WHEN** таймаут синтеза или число повторов задан неположительным
- **THEN** настройки не загружаются и выдаётся понятная ошибка до платных вызовов
