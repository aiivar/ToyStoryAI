## Context

См. `proposal.md` — Why. Замеры трёх приёмных прогонов изменения `add-story-style-profile` (по 6 страниц, один и тот же сюжет для пары `junior`, отдельный для `senior`):

| Замер | `junior`, 1-е лицо | `junior`, 3-е лицо | `senior`, 1-е лицо | Ориентир в коде |
|---|---|---|---|---|
| Длина фразы, слов | 5,30 | 4,59 | 5,48 | 7–10 / 8–10 |
| Доля реплик | 12,6 % | 14,6 % | 27,6 % | 12–19 % |
| Диминутивы на 1000 | 49,89 | 50,74 | 14,68 | 8–17 / 10–20 |
| Модальные оговорки | 2,17 | 2,11 | 6,29 | 3–5 |
| Многоточия на 1000 | 4,34 | 21,14 | 2,10 | 5–10 / 7–12 |
| Короткие фразы | 17,2 % | 21,4 % | 23,0 % | 4–7 % / 5–7 % |
| Атрибуция на 1000 | 0 | 0 | 0 | ≤ 6 / ≤ 5 |

Все три текста признаны качественными: манера читается, мораль не проговорена, судья либо пропустил, либо поймал настоящие дефекты (расхождение сцены, вывод-обобщение). При этом метрика нашла 4–5 грубых отклонений в каждом.

Причина расхождения: ориентиры снимались с корпуса для 8–14 лет, где фраза длиннее и диминутивы распределены по многим персонажам. В наших текстах герой — игрушка с уменьшительным именем, повторяющимся на каждой странице, а ритм для 3–6 короче по определению.

## Goals / Non-Goals

**Goals:**

- Отчёт о манере перестаёт шуметь: на хорошем тексте отклонений нет, на испорченном — есть.
- Счётчик диминутивов измеряет приём, а не имя героя.
- Стиль-починка не тратит вызов впустую из-за пустого ответа.
- Калибровка закреплена регрессионными тестами на реальных текстах.

**Non-Goals:**

- Менять контракт `story-style` (отчёт остаётся сигналом, не гейтом).
- Делать метрики блокирующими.
- Менять промпты или профильные приёмы: калибруются только числа и подсчёт.

## Decisions

### 1. Ориентиры пересчитываются по живым текстам, а не по корпусу

Новые значения (границы «нормы», запас «грубости» 20 % сохраняется):

| Замер | `junior` | `senior` |
|---|---|---|
| Длина фразы, слов | 4,5–7,0 | 5,0–8,0 |
| Доля реплик | 12–19 % | 12–30 % |
| Диминутивы на 1000 | 6–20 | 8–22 |
| Модальные оговорки на 1000 | 2,0–7,0 | 2,0–7,0 |
| Многоточия на 1000 | 3,0–25,0 | 2,0–15,0 |
| Короткие фразы | 10–30 % | 10–30 % |
| Атрибуция, не более | 6 | 5 |

Диапазоны намеренно широкие: их задача — отсечь текст, написанный вообще не в этой манере (длинные периоды, отсутствие диалога, энциклопедичность), а не ловить стилистические колебания. Узкие окна на выборке 450–500 слов всё равно дают случайные срабатывания.

Альтернатива — оставить прежние числа и считать шум допустимым — отклонена: отчёт, который всегда красный, перестают читать, и настоящее отклонение в нём не заметят.

### 2. Имена персонажей исключаются из счётчика диминутивов

`measure_style` получает имена персонажей из реестра сущностей и пропускает токены, основа которых совпадает с основой имени (первые три буквы в нижнем регистре: «Мишка» → «миш», отсюда «Мишенька» тоже пропускается).

Обоснование: уменьшительное имя героя — социальная оптика (так его зовут другие), но его повторяемость в тексте измеряет не приём, а частотность обращения к герою. Без исключения один персонаж даёт 35–50 диминутивов на 1000 слов, и настоящий сигнал («цветочек», «домик», «солнышко») в нём тонет.

Альтернатива — поднять потолок до 55 — отклонена: тогда «сюсюканье» перестаёт обнаруживаться вовсе. Основы в три буквы могут дать ложное совпадение («мишура»), но это сигнал, а не гейт.

### 3. Пустой ответ стиль-починки повторяется один раз

Первый приёмный прогон получил от DeepSeek пустую строку, изолированный повтор того же запроса прошёл. Клиент считает пустой ответ постоянной ошибкой, поэтому внутри стиль-починки добавляется один повтор: бюджет остаётся «одна применённая починка на прогон», но плавающий отказ не отменяет её целиком.

Альтернатива — править только страницы с отклонениями — пока отклонена: замеры общие по сказке, и локальная правка не гарантирует выполнения ориентиров. Если повтор не поможет и пустые ответы окажутся системными, это станет отдельным решением.

### 4. Реальные тексты становятся фикстурами

Три приёмных текста кладутся в `tests/story_pipeline/fixtures/style/` и проверяются дважды: как «хорошие» (отклонений нет) и как «испорченные» после детерминированной порчи (удлинить фразы, убрать реплики) — отклонения появляются.

Альтернатива — синтетический текст в тесте — отклонена: именно синтетика и разошлась с жизнью в первый раз.

## Risks / Trade-offs

- **Подгонка под три текста.** Широкие диапазоны снижают риск, но калибровка по трём прогонам всё равно смещена → после серии из десяти прогонов числа пересматриваются; тест на фикстурах фиксирует только отсутствие шума.
- **Основы имён в три буквы дают ложные совпадения** → это сигнал, не гейт; при систематической ошибке основа удлиняется до четырёх букв с проверкой на реальных текстах.
- **Повтор пустого ответа повышает цену починки** → повтор выполняется только при пустом ответе, а не при любом сбое; бюджет вызовов остаётся ограниченным.
- **Отчёт станет «зелёным» на тексте, который слабо отличается от манеры** → за это отвечает пятый критерий судьи, а не числа; калибровка не отменяет его.

## Migration Plan

Миграции нет: `style_report` в старых артефактах остаётся как есть, новые прогоны пишут отчёт по новым ориентирам. Откат — возврат чисел в `style.py`.

## Open Questions

Нет. Значения после серии из десяти прогонов уточняются тем же механизмом, без изменения подхода.
