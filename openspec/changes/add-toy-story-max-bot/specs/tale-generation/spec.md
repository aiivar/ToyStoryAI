## Purpose

Генерация персональной, безопасной для детей сказки на русском языке, в которой главным героем выступает игрушка пользователя, с использованием настраиваемой внешней языковой модели.

## ADDED Requirements

### Requirement: Требования к содержанию сказки
Сгенерированная сказка ДОЛЖНА (SHALL) быть написана на русском языке, содержать 150–300 слов, главным героем ДОЛЖНА (SHALL) быть сфотографированная игрушка, соответствовать выбранному стилю и действию, не содержать страшных сцен и подходить детям 3–10 лет.

#### Scenario: Сказка сгенерирована по выбранным параметрам
- **WHEN** пользователь выбрал стиль и действие и сказка сгенерирована
- **THEN** полученная сказка написана на русском языке, содержит 150–300 слов, главный герой — игрушка, и отражены выбранные стиль и действие

#### Scenario: Соблюдено требование безопасности
- **WHEN** генерируется любая сказка
- **THEN** запрос предписывает модели избегать страшных сцен и контента, неподходящего детям 3–10 лет

#### Scenario: Стиль влияет на повествование
- **WHEN** пользователь выбирает «Волшебная», «Смешная» или «Приключенческая»
- **THEN** стиль сгенерированной сказки соответствует выбранному варианту

#### Scenario: Действие отражено в сказке
- **WHEN** пользователь выбирает «Танец», «Полёт» или «Путешествие»
- **THEN** сгенерированная сказка включает это действие, выполняемое игрушкой

### Requirement: Настраиваемая модель генерации сказки
Система ДОЛЖНА (SHALL) использовать языковую модель, задаваемую через переменные окружения, по умолчанию быструю `deepseek-flash` и с возможностью использовать `deepseek-v4-pro`.

#### Scenario: Модель выбирается конфигурацией
- **WHEN** модель для сказки задана в переменных окружения
- **THEN** система использует эту модель для генерации сказки без изменений кода

#### Scenario: Используется модель по умолчанию
- **WHEN** модель для сказки не задана
- **THEN** система использует быструю модель по умолчанию

### Requirement: Устойчивость генерации сказки
Система ДОЛЖНА (SHALL) повторять временно неуспешные попытки генерации сказки до трёх раз с экспоненциальной задержкой и сообщать о сбое, если все попытки не удались.

#### Scenario: Временный сбой повторяется
- **WHEN** запрос генерации сказки падает с временной ошибкой
- **THEN** система повторяет до трёх попыток с увеличивающейся задержкой между ними

#### Scenario: Все попытки неуспешны
- **WHEN** все попытки повторения не удались
- **THEN** система поднимает ошибку генерации, и бот сообщает о ней пользователю

#### Scenario: Ошибка аутентификации не повторяется бесконечно
- **WHEN** API генерации сказки отклоняет учётные данные
- **THEN** система завершает шаг неудачей, не расходуя попытки на нетранзиентную ошибку
