## REMOVED Requirements

### Requirement: Озвучка только текста страниц
**Reason**: постраничный синтез заменён одним запросом на весь текст сказки. Требование о слышимой паузе между страницами больше не действует: паузы расставляет сама речь, а нарезка запроса по страницам запрещена.
**Migration**: заменено требованием «Озвучка текста страниц одним запросом» этой же capability; остальные требования `story-narration` не меняются.

## ADDED Requirements

### Requirement: Озвучка текста страниц одним запросом

Система ДОЛЖНА (SHALL) озвучивать исключительно тексты страниц в порядке их номеров. Система ДОЛЖНА (SHALL) не добавлять от себя вступление, заголовок сказки, обращение к слушателю, мораль или слово «Конец». Текст всех страниц ДОЛЖЕН (SHALL) синтезироваться одним запросом к провайдеру; искусственные паузы на границах страниц не добавляются, а границы страниц не ДОЛЖНЫ (SHALL NOT) служить границами запросов. Только если объём текста превышает лимит запроса модели, допускается нарезка по границам предложений без привязки к страницам.

#### Scenario: Текст страниц идёт по порядку
- **WHEN** сказка содержит страницы 1..N
- **THEN** в аудиофайле звучат тексты этих страниц без пропусков и в порядке номеров

#### Scenario: Ничего не дописано от системы
- **WHEN** аудиофайл озвучен
- **THEN** в нём нет вступления, заголовка, морали и завершающей фразы, которых нет в текстах страниц

#### Scenario: Один запрос на всю сказку
- **WHEN** текст всех страниц помещается в лимит запроса модели
- **THEN** провайдер синтеза вызывается один раз с текстом всей сказки

#### Scenario: Границы страниц не режут запрос
- **WHEN** сказка содержит несколько страниц
- **THEN** текст запроса содержит все страницы подряд, а не отдельные запросы на каждую страницу

#### Scenario: Длинный текст режется по предложениям
- **WHEN** текст сказки превышает лимит одного запроса
- **THEN** он делится по границам предложений, а не по страницам, и склеивается без искусственных пауз
