## Why

Озвучка звучит как набор отдельных страниц: на каждой границе интонация
начинается заново, между страницами слышна искусственная пауза 400 мс, а темп
и громкость соседних страниц расходятся, потому что их синтезируют независимые
параллельные запросы.

Причина — в этапе `NarrationStage`, а не в провайдере: текст режется по
страницам ещё до обращения к модели, на каждую страницу уходит отдельный
HTTP-вызов, а сегменты склеиваются с принудительной паузой. При этом весь текст
сказки помещается в лимит модели: 12 страниц по 120 слов — это примерно
9–10 тыс. знаков при лимите промпта 8192 токена.

## What Changes

- `NarrationStage` собирает тексты страниц в один текст и синтезирует его
  одним запросом к провайдеру.
- Предел текста на один запрос поднимается с 1200 до 12000 знаков — с запасом
  на максимальную сказку из настроек.
- Нарезка остаётся только страховкой для аномально длинного текста и идёт по
  границам предложений, без привязки к страницам.
- Искусственная пауза 400 мс между страницами убирается: паузы даёт сама речь
  на знаках препинания и абзацах.
- Тесты фиксируют один вызов провайдера на обычную сказку, отсутствие
  постраничной нарезки и сохранение fallback-нарезки по лимиту.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `story-narration`: весь текст сказки синтезируется одним запросом;
  искусственная пауза на границе страниц больше не добавляется, а нарезка по
  страницам запрещена — только по границам предложений при превышении лимита.

## Impact

- Код: `app/story_pipeline/stages/narration.py`, `app/story_pipeline/audio.py`,
  `tests/story_pipeline/test_narration.py`.
- Настройки окружения не добавляются. `ROUTERAI_NARRATION_CONCURRENCY`
  сохраняется для fallback-нарезки длинного текста, его описание в README и
  `.env.example` уточняется.
- Размен: один запрос на всю сказку дольше и дороже за раз, а его сбой теперь
  означает отсутствие всей озвучки. Управляемая деградация уже предусмотрена:
  книжка доставляется без аудио, причина остаётся в `narration_error`.
