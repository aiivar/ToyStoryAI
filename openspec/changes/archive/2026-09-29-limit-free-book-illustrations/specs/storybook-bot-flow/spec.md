## MODIFIED Requirements

### Requirement: Постраничная выдача результата
Бот ДОЛЖЕН (SHALL) отдавать готовую сказку постранично: для каждой страницы одно сообщение с заголовком «Страница N», текстом страницы и, если страница входит в набор иллюстрируемых, прикреплённой картинкой. Страницы вне набора иллюстрируемых ДОЛЖНЫ (SHALL) отдаваться текстом без вложения и без сообщения о неудаче, поскольку картинки для них не заказывались.

#### Scenario: Страницы приходят по порядку
- **WHEN** генерация завершилась успешно
- **THEN** пользователь получает сообщения по одной на страницу, в порядке номеров страниц, каждое с текстом своей страницы и картинкой для страниц набора

#### Scenario: Текст и картинка рядом
- **WHEN** отправляется страница из набора иллюстрируемых
- **THEN** текст страницы и её картинка находятся в одном сообщении

#### Scenario: Страница вне набора приходит текстом
- **WHEN** отправляется страница, не входящая в набор иллюстрируемых
- **THEN** сообщение содержит только номер и текст страницы, без вложения и без упоминания неудачной картинки

#### Scenario: Картинка не загрузилась
- **WHEN** вложение не удалось отправить
- **THEN** бот сообщает об этом понятным текстом, а текст страницы остаётся у пользователя

### Requirement: Частичный результат
Если пайплайн завершился со статусом «требует проверки», бот ДОЛЖЕН (SHALL) отдать то, что готово, и ДОЛЖЕН (SHALL) честно описать, что именно требует внимания: пропущенные иллюстрации у страниц из набора иллюстрируемых — если они есть, и оставшиеся замечания к тексту — если все иллюстрируемые страницы отданы с картинками. Пропуски ДОЛЖНЫ (SHALL) считаться по набору иллюстрируемых страниц: страницы вне набора пропусками не являются и частичным результатом прогон не делают. Квота ДОЛЖНА (SHALL) начисляться только когда книжка доставлена целиком; прогон с пропущенными иллюстрациями у страниц набора квоту не расходует.

#### Scenario: Часть страниц без картинки
- **WHEN** пайплайн отдал картинки для части страниц набора, а у другой страницы набора картинки нет
- **THEN** бот отдаёт все готовые страницы, а для пропущенной объясняет причину и предлагает сделать сказку заново

#### Scenario: Отсутствие картинок по замыслу не делает результат частичным
- **WHEN** у части страниц нет картинки, и все эти страницы вне набора иллюстрируемых
- **THEN** прогон не считается частичным, квота расходуется, а повтор не предлагается

#### Scenario: Квота не тратится при частичном результате
- **WHEN** генерация завершилась с частичным результатом
- **THEN** запись в БД не засчитывается как завершённая сказка, а бот предлагает сделать сказку заново один раз в рамках того же диалога

#### Scenario: Квота расходуется, когда все страницы отданы
- **WHEN** пайплайн завершился со статусом «требует проверки», но у всех страниц набора есть иллюстрации (например, исчерпан бюджет ревизий)
- **THEN** бот отдаёт книжку целиком, сообщает, что замечания остались к тексту, записывает статус успеха и не предлагает повтор

### Requirement: Цепочка референсов фото → лист → страницы
Бот ДОЛЖЕН (SHALL) создавать character sheet с фото игрушки как единственным reference-изображением, а каждую иллюстрируемую страницу — с character sheet, и ДОЛЖЕН (SHALL) использовать число страниц, равное значению по умолчанию из настроек. Character sheet ДОЛЖЕН (SHALL) создаваться независимо от бюджета иллюстраций: он остаётся единым якорем внешности для всех страниц, которые рисуются, и при нулевом бюджете это якорь для всех страниц.

#### Scenario: Лист строится по фото игрушки
- **WHEN** генерируется character sheet
- **THEN** единственным reference-изображением в вызов уходит фото игрушки, а не лист и не пустой набор

#### Scenario: Страницы строятся по листу
- **WHEN** генерируются страницы
- **THEN** единственным reference-изображением в каждый вызов уходит character sheet

#### Scenario: Число страниц берётся из настроек
- **WHEN** запускается генерация
- **THEN** число страниц равно значению по умолчанию из настроек пайплайна, а не задаётся в коде обработчика

#### Scenario: Лист не зависит от бюджета иллюстраций
- **WHEN** бюджет иллюстраций ограничен и в книжке рисуется лишь часть страниц
- **THEN** character sheet всё равно создаётся и используется как референс для каждой нарисованной страницы
