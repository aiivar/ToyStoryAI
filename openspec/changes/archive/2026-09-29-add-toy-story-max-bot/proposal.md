## Why

У родителей и детей нет простого способа превратить любимую физическую игрушку в интерактивную историю. Бот в мессенджере MAX может принять фотографию игрушки, сгенерировать персональную сказку на русском языке и анимировать фото в короткое видео — отдав и то и другое прямо в чат без установки приложения. Это новый greenfield-продукт без существующего кода, поэтому MVP должен с нуля создать бота, обе AI-интеграции, хранение данных и квоту.

## What Changes

- Новый асинхронный сервис на Python 3.11+, запускающий бота MAX через длинный polling библиотекой `maxapi` к `platform-api2.max.ru`.
- Новый онбординг по `/start` с кнопкой «Загрузить фото игрушки» и пошаговым FSM-диалогом.
- Новый приём фото игрушки с валидацией (jpg/png/webp, ≤10 МБ, ≥300×300 px, соотношение сторон 1:2.5–2.5:1), локальным хранением и передачей изображения в base64 видеопровайдеру.
- Новая генерация сказки через OpenAI-совместимый API DeepSeek (`deepseek-flash` / `deepseek-v4-pro`): русский язык, 150–300 слов, игрушка — главный герой, без страшных сцен, для детей 3–10 лет, в выбранном стиле.
- Новая генерация видео из фото через Kling AI (через настраиваемого провайдера, например GMI Cloud): 5 с, 720p `std`, звук выключен, асинхронное создание задачи и polling статуса, с mock-заглушкой при отсутствии API-ключа и абстракцией провайдера.
- Новая история генераций в SQLite через SQLAlchemy 2.0 async + aiosqlite (пользователь, время, тип, статус, ссылки на файлы, ID запроса к Kling).
- Новое правило квоты: одна бесплатная полная генерация (сказка + видео) на пользователя; последующие запросы блокируются с предложением подписки (в MVP — заглушка).
- Новый базовый набор упаковки и эксплуатации: `.env.example`, `requirements.txt`, `Dockerfile`, `docker-compose.yml`, `README.md` и тесты сервисов на pytest с моками внешних API.

Вне рамок этого MVP: реальная обработка платежей и подписок, другие типы медиа, горизонтальное масштабирование, вывод на других языках и админ-аналитика.

## Capabilities

### New Capabilities
- `bot-conversation`: онбординг по `/start`, FSM-диалог, выбор стиля и действия, уведомления о прогрессе и выдача пользователю текста сказки и видео.
- `toy-photo-intake`: приём, валидация, хранение и подготовка изображения входящего фото игрушки в base64 для видеопровайдера.
- `tale-generation`: генерация сказки через DeepSeek с требованиями к языку, объёму, безопасности и стилю.
- `toy-animation`: генерация видео из фото через Kling, асинхронный жизненный цикл запроса, polling, абстракция провайдера и mock-заглушка.
- `generation-history`: сохранение и чтение записей о генерациях и их статусов.
- `usage-limits`: контроль квоты бесплатных генераций и предложение подписки для последующих запросов.

## Impact

- **Новый код**: пакет `app/` (`main.py`, `config.py`, `bot/`, `services/`, `db/`, `utils/`), `tests/` и служебные файлы в корне проекта.
- **Новые внешние зависимости**: `maxapi`, `httpx`, `pydantic` v2 / `pydantic-settings`, `sqlalchemy[asyncio]`, `aiosqlite`, `python-dotenv`, `tenacity`, `loguru` (опционально), `pytest`, `pytest-asyncio`.
- **Внешние API**: MAX Bot API (`platform-api2.max.ru`), DeepSeek (`api.deepseek.com`), Kling AI через настраиваемого провайдера (по умолчанию GMI Cloud).
- **Конфигурация**: все секреты через `.env` (`MAX_BOT_TOKEN`, `DEEPSEEK_API_KEY`, `KLING_API_KEY`, `DATABASE_URL`, настройки polling и таймаутов).
- **Рабочие артефакты**: локальная папка `uploads/` и файл `bot.db` SQLite.
- **Стоимость**: каждая не-mock генерация видео стоит ≈$0.42 (720p std, 5 с, звук выключен); квота в одну бесплатную генерацию ограничивает расход на пользователя.
