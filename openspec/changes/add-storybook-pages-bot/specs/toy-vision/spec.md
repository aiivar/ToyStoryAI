## Purpose

Распознавание игрушки по присланному фото, чтобы текст сказки и её иллюстрации описывали один и тот же персонаж. Описание, полученное один раз, становится единственным источником правды для планировщика, экстрактора и промптов изображений.

## ADDED Requirements

### Requirement: Распознавание игрушки по фото
Система ДОЛЖНА (SHALL) выполнять один вызов языковой модели с переданным изображением и возвращать описание игрушки с полями `kind`, `color`, `material`, `features` и `short`.

#### Scenario: Описание получено
- **WHEN** в сервис распознавания переданы байты фото игрушки
- **THEN** возвращается заполненное описание с видом, цветом, материалом и характерными деталями

#### Scenario: Описание используется как источник правды
- **WHEN** описание получено
- **THEN** оно передаётся в тему для планировщика, в подсказку экстрактору описаний героя и в промпт reference-изображения

#### Scenario: Запрос детерминирован
- **WHEN** выполняется распознавание
- **THEN** вызов использует низкую температуру (0.2) и JSON-режим, чтобы описание не «дрейфовало» между прогонами

#### Scenario: Фото передаётся без файловой системы
- **WHEN** в запрос передаётся фото
- **THEN** изображение передаётся как data URI, без публичного URL и без промежуточного файла

### Requirement: Отказы распознавания
Система ДОЛЖНА (SHALL) повторять временную ошибку один раз, поднимать типизированную понятную ошибку при постоянной (включая неподдержку изображений моделью) и не раскрывать ключ в ошибках и логах.

#### Scenario: Временная ошибка повторяется
- **WHEN** первый вызов завершился временной ошибкой
- **THEN** выполняется одна повторная попытка

#### Scenario: Модель не поддерживает изображения
- **WHEN** модель отклонила запрос с изображением
- **THEN** система поднимает типизированную ошибку с сообщением для пользователя, а не выпускает сказку с придуманным героем

#### Scenario: Секрет не утекает
- **WHEN** возникает ошибка распознавания
- **THEN** в тексте ошибки и в логах нет значения ключа

#### Scenario: Пустое описание
- **WHEN** модель вернула ответ, не соответствующий схеме
- **THEN** система поднимает типизированную ошибку, а не подставляет выдуманное описание
